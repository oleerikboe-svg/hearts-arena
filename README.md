# Hearts Arena v44 – Public Online Test

Browser Hearts game with authoritative Node/WebSocket multiplayer.

## Public deployment
The Node service serves both the website and WebSocket endpoint. On HTTPS, the client automatically connects to `wss://<same-host>/ws`.

## Local test
```
npm install
npm start
```
Open http://localhost:8080.
