# Hearts Arena Android

Android wrapper for the existing Hearts Arena web app.

## First build
1. Install Android Studio (current stable) with Android SDK 35.
2. Open the `android` folder as a Gradle project.
3. Let Gradle sync.
4. Run the `app` configuration on a phone/emulator.

The app is landscape-first and loads the public game at:
https://hearts-arena.onrender.com/?android=1

Online play uses the same HTTPS/WSS Render service as the browser version.
